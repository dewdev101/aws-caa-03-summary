# Gold and black AWS topic icon atlas

Generated with the built-in image generation tool. The 4 × 4 transparent atlas is displayed as a responsive CSS sprite sheet; its first 14 cells map to the 14 AWS study categories in `content/notes.tsx` order.

## Prompt

Create a production-ready sprite atlas of 14 distinct semantic icons for a Japanese-inspired AWS learning website. Use a strict palette of antique metallic gold and deep matte black only; no red, orange-red, white, blue, green, colored glow, or colored shadows. No text, letters, numerals, or logos. Use a regular four-column by four-row grid with transparent background. Each cell has a centered circular black medallion with a fine gold outline and a crisp, legible gold pictogram. The first fourteen cells, in reading order, represent: networking globe, storage servers, cloud object storage bucket, database, compute lightning bolt, IAM/security shield with person, management control sliders, disaster recovery shield with circular arrow, high availability heart with pulse, performance speedometer, billing coins, analytics rising chart, Japanese temple for governance, and API connected nodes with code brackets. Leave the final two cells empty. Keep the icon style consistent, clean, restrained, and readable at small sizes; no sparkles, extra decoration, colored fringes, or shadows.
